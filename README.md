# Neosanpo / まよいみち v3.1

実際の街を歩き、ひとつだけでも面白いアイテムを拾うスマホ向け散歩アプリです。現在地の道路をそのままに、城・魔法使いの塔・樹上の村・遺跡のAIイラストを地図へ重ねます。

## 今回の変更

- 家の中から近くの道路を始点にしてルートを確認できるように修正。
- 建物の近くの細い道路、歩道タグのない一般道路、最寄りの孤立した道の扱いを修正。
- 建物のID・位置・種類・地上での大きさを固定。ズームや再読込で再抽選しない。
- 今後の追加用設定を `src/structures.ts` に集約。既存の割当を変更せず追加できる。
- 下部の小型UI、実歩行での取得、通行制限区域の除外は継続。

**全国の地物に同じ描画方式を適用します。全国の各地域を別々のAI画像として生成済みではありません。** 詳細と次の工程は [地図生成の設計](docs/FANTASY_MAP.md)。

## スマホでの使い方

1. Cloudflare Pagesなどに配信したHTTPS URLをSafari / Chromeで開く。
2. 「現在地から始める」で、正確な位置情報の利用を許可する。
3. アイテムを選び「ルートを表示」。アプリを開いたまま、実際に歩く。
4. 到着が確認されたら「拾う」。コレクションはブラウザに保存される。

地図を動かすだけでは取得できません。画面ロック・アプリ切替で測位が中断した場合は、歩行確認を取り直します。入れない場所はアイテム詳細の「この場所には行けない」で非表示にできます。

地図に未登録の私道・通行規制まで保証することはできません。学校等の区域データ取得に失敗したときは目的地を生成しません。家や敷地の中では近くの道路からルートを表示し、「まず道路に出てください」と案内します。敷地から道路までの推測した線は描きません。接続できる道路が遠いときは、移動後に再検索します。

## 起動

Node.js 22.18以上。検証環境：Node.js 26.8.1。

```sh
npm ci
npm run dev
```

PCで http://127.0.0.1:5173 を開きます。APIキーは不要。インターネット接続・WebGL・位置情報が必要です。スマホでGPSを使うにはHTTPSが必要です。[Cloudflare Pagesと実機確認](docs/PHONE_SETUP.md)。

## 検証・配布

```sh
npm test
npm run format:check
npm run build
npm run preview
```

配布用は `dist/`。Cloudflare Pagesのビルドコマンドは `npm run build`、出力ディレクトリは `dist`。

preview起動後、別ターミナルで：

```sh
npx playwright install chromium
BASE_URL=http://127.0.0.1:4173 npm run test:browser
BASE_URL=http://127.0.0.1:4173 npm run test:errors
python3 scripts/package-release.py
```

ZIPは `release/mayoimichi-v3.1.0.zip`。ソース・配布ビルド・生成素材・文書を同梱。模擬GPSはテスト専用で、アプリには含まれません。屋外の実機検証とは区別しています。

今回の変更はローカルに保存しています。GitHubへのPush・Cloudflareへの反映はこの作業では実施していません。

建物固定の回帰テストは開発サーバーを使います。`npm run dev -- --port 5180` を起動し、別ターミナルで `npm run test:stability` を実行します。

## 歩行条件・保存

- 出発地点から120m以上離れた目的地。
- 精度25m以内、10秒以内の新しいGPS測位。
- 30秒以上経過、誤差を差し引いた連続歩行40m以上・3区間以上、出発地点から50m以上移動。
- 到着は「目的地までの距離＋位置精度」が35m以内、低速で8秒以上・3測位以上。
- 瞬間移動・速度超過・長い中断では連続歩行を取り直す。
- 保存キーは従来どおり `mayoimichi:v2`。UIの版とは別。既存の実散歩データを維持。
- 非表示地点は `neosanpo:hidden-places`。端末内だけで保存し、報告を外部送信しない。
- 現在地や連続した移動軌跡は永続化しない。取得品・場所ID・名前・日時・歩行距離・音設定を保存。

## 通信・制約

地図はOpenFreeMap、道路・制限区域はOverpass API。現在地付近の座標を送信します。Google Fontsを使用します。公開APIの混雑時は再検索が必要で、全国の動作・情報網羅性を保証するものではありません。

ストーリー・クラウド同期・バックグラウンドGPS・オフライン・GPS偽装を防ぐサーバー・地域固有の全国AI画像は未実装。iOS / Androidでの実際の屋外歩行は未確認です。
