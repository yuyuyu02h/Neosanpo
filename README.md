# まよいみち v2

**スマホを持って、いつもの道の向こうがわへ。**

実際の現在地を緑の異世界として表示し、現実の街を歩いて奇妙な忘れものを拾う散歩アプリです。ロボットの頭、誰かが舐めた飴、ハエのうんち、知らないおじさんの五七五など、独立した絵と文章のある12種類を収録しています。

v2は実際の位置情報専用です。固定の開始地点、移動ボタン、試し歩きモードはありません。

## スマホでの遊び方

1. HTTPSで配信されたアプリのURLをSafariまたはChromeで開く。
2. 「現在地から、散歩を始める」で位置情報と正確な位置の利用を許可する。
3. 現在地の周辺に出る気配を選び、「ここへ、歩き始める」を押す。
4. アプリを開いたまま現実の道を歩く。GPS位置に合わせて地図の中の自分も進む。
5. 目的地付近で位置が安定すると「足もとを見てみる」が表示される。拾ったものは端末に保存される。

「現実」で元の地図へ切り替えられます。距離は直線距離で、徒歩経路案内ではありません。現在地へ戻すボタンや地図の操作で、取得条件を満たすことはできません。

位置の精度が悪いときは、空の見える場所で待ってください。画面ロックやアプリの切替で測位が中断した場合は、戻ってから歩行確認をやり直します。対応端末では散歩中の画面消灯を抑えます。

## 開発起動

Node.js 22.18以上とnpmを使用。検証環境はNode.js 26.8.1。

```sh
npm ci
npm run dev
```

PCの <http://127.0.0.1:5173> で開きます。APIキー・環境変数・アカウントは不要。地図にはインターネット接続とWebGLが必要です。

**このURLはPC専用です。スマホで実際に散歩するにはHTTPSで配信する工程が必要です。現在は未公開です。** PCのローカルIPをHTTPでスマホから開いても位置情報は利用できません。[スマホ配信と実地検証](docs/PHONE_SETUP.md)を参照してください。

## 確認と書き出し

```sh
npm test
npm run build
npm run preview
```

`dist/` がHTTPSの静的ホストへ配置する配布ファイルです。ルートパスへの配置を想定。previewは <http://127.0.0.1:4173> 。

開発サーバー起動中に、専用ブラウザで操作を検証できます。

```sh
npx playwright install chromium
npm run test:browser
npm run test:errors
```

`BASE_URL=http://127.0.0.1:4173 npm run test:browser` で配布ビルドを検証できます。テスト専用のGPS入力は `tests/gps-harness.mjs` にあり、配布物には含まれません。実機を持って歩いた検証とは区別しています。画像は `test-results/`。

```sh
npm run format:check
python3 scripts/package-release.py
```

配布ビルド・ソース・文書を `release/mayoimichi-v2.0.0.zip` へまとめます。

## 取得条件と保存

- 選択する目的地は現在地から120m以上。
- 精度25m以内、10秒以内の新しい測位が必要。
- 30秒以上経過し、誤差を差し引いた連続歩行40m以上・3区間以上、出発地点から50m以上移動。
- 目的地までの距離＋位置精度が35m以内で、低速状態を8秒以上・3測位以上確認。
- GPSの飛び、速度超過、長い中断では連続歩行を取り直す。
- 保存先は `localStorage` の `mayoimichi:v2`。旧 `mayoimichi:v1` は消さず、実散歩の記録だけ読み込む。
- 品、取得場所ID・名前、日時、距離、音設定を保存。現在地や連続した移動軌跡は永続化しない。
- 記録はブラウザごと。JSON出力はできるが取り込みは未対応。

## 通信と表現

OpenFreeMapの実地図に、森・家のSVGと独自配色を重ねています。道と建物の位置は保持します。周辺候補はOverpass API、失敗時は小範囲のOpenStreetMap APIから取得。座標が地図サービスへ送られることを開始前に案内します。Noto Serif JPはGoogle Fontsを使用し、読めないときは端末フォントへ戻ります。

生成AIによる地図画像の書き換えは未実装です。ストーリー、徒歩ナビ、バックグラウンドGPS、アカウント同期も含みません。屋外実機検証とHTTPS公開は未完了です。
