# 保守・引き継ぎ v2

## 今回の修正

利用者の意図は「スマホを持って実際に歩く」。v1の固定公園・試し歩きを中心とした導線は意図と異なっていたため、GPSだけの体験に変更した。元の発想は `CONCEPT.md`、確定仕様は `REQUIREMENTS.md`。

- 初期位置なし。正確な測位後に実際の地点の地図を作る。
- ボタンで位置を動かす処理は配布物から分離。
- 取得条件に連続歩行・精度・測位の鮮度・到着の安定を追加。
- 旧版の試し歩きによる収集品はv2へ持ち込まない。元データは消さない。
- スマホ開始画面、ホーム画面アイコン、消灯抑制、GPS再取得と障害案内。

## 変更方法

- 歩行条件：`src/walking.ts`。変更時は静止・瞬間移動・中断・到着のテストを維持する。
- 品：`src/items.ts` と `src/art.ts`。保存済みの品IDは変えない。
- 周辺候補：`src/places.ts`。拾得済み地点を特定するOSM IDを維持。私有地等の除外を残す。
- 地図：`src/map.ts`。色・模様を変えても実際の道路・水域の座標を移動させない。
- UI：`src/main.ts` / `src/style.css`。地図のマーカーが操作カードを覆わない `#world-map` の重なり設定を維持。
- 保存：`src/storage.ts`。仕様変更時はバージョンと移行処理を更新し、読めないデータを上書きしない。

## 既知の制約・残作業

1. HTTPS公開と実際の屋外歩行は未実施。`PHONE_SETUP.md` に手順と確認項目を記録。
2. ブラウザのGPSは端末と環境で品質が異なる。閾値は模擬測位で確認した初期値。実機データで調整する。
3. 画面非表示・ロック中の歩行を保証しない。中断後の連続距離は取り直す。
4. GPS偽装・ブラウザの改変への耐性はない。認証・サーバー検証は未実装。
5. ベンチ等がOSMに未登録の地域では目的地が出ない。立入可否や現況を保証する経路案内ではない。
6. 異世界表現はSVGと地図スタイル。元の「AIで地図の外観を書き換える」処理は未実装の構想として残す。
7. 12種類の割当は地点IDから固定。同じ種類を別の地点で拾うことはある。同じ地点は一度だけ。
8. 自動同期・JSON取り込み・オフライン・ストーリーは未実装。
