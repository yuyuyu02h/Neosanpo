# 保守・引き継ぎ v3

## 今回の変更

地図を広く見せる小型の下部操作バー、自然な文言、道路に沿った徒歩ルート、私有地・学校等の区域除外、AI生成素材の配置を実装した。要件は `REQUIREMENTS.md` 冒頭のv3。v2部分は履歴。

## 変更時の注意

- 歩行条件：`src/walking.ts`。静止・瞬間移動・中断・到着の検証を維持。
- 経路・区域：`src/navigation.ts`。端点だけでなく、線分が禁止区域を横切る場合も除外する。
- 検索：`src/places.ts`。道路だけ取得できても区域取得が不完全なら候補を作らない。`remark` のある応答を採用しない。
- 地図：`src/map.ts`。道路座標を変えない。MultiPolygonは全形状を扱う。建物の表示倍率制限で高倍率の形状を失わないようにする。
- 素材：`docs/ASSETS.md`。元PNGは `assets/source-art`、配信用は `public/fantasy`。
- UI：`src/main.ts` / `src/style.css`。375px幅でも操作バーで地図を覆わない。現在地・目的地をカードの余白を考慮して表示。
- 保存：既存キー `mayoimichi:v2` は維持。品IDは変更しない。壊れた保存値を上書きしない。

## 既知の制約

1. OSMの未登録・誤登録の私道や、現場の臨時規制は判別できない。非表示機能は端末内だけで共有されない。
2. 厳しめの区域除外で候補が出ない地域がある。屋内・学校・敷地から出発すると公共道路に接続できない場合もある。
3. 公開Overpass APIは混雑や停止がある。取得量を抑え、5分/250mで結果を再利用。運用拡大時はキャッシュサーバー等を検討。
4. 建物・公園の地物が乏しい地域はAI建築も少ない。アイコンは衝突を避けて間引かれる。
5. 現状は生成済みAI素材の全国配置。全国の地域固有画像の生成・保存・配信は未実装。`FANTASY_MAP.md` に分けて記録。
6. iOS / Androidの屋外歩行、消灯抑制、電池消費、低速回線は未確認。バックグラウンド測位・偽装防止・同期は未実装。
7. 同じアイテムが別の地点に出る場合がある。同じ地点では一度だけ取得。

## リリース

`npm test` → `npm run format:check` → `npm run build` → previewに対してブラウザ2スクリプト → `python3 scripts/package-release.py`。

今回、GitHubへのPush・Cloudflareへの公開操作はしていない。既存Pagesの設定は `PHONE_SETUP.md`。ZIPはソース・dist・素材・文書を含み、`archive/v1-demo` は含めない。
