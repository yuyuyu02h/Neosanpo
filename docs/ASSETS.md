# AI素材の制作記録

制作：2026-10-01。Codexの内蔵画像生成（image_gen）で5点を制作。

| 素材    | 用途                           |
| ------- | ------------------------------ |
| castle  | 苔に覆われたケルトの石造りの城 |
| tower   | 魔法使いの塔、青い光と螺旋階段 |
| village | 巨木の上の村と木の橋           |
| ruins   | 円形の砦、石の遺跡、魔法陣     |
| terrain | 草・苔・シダの繰り返し地形     |

生成元PNGは `assets/source-art/`、配信用WebPは `public/fantasy/`。元画像を保存し、ブラウザでWebPへ変換した。城・塔・村・遺跡は透過背景。地形は不透過。使用時に縮小して地図の画像として登録する。元画像は静的サイトに配信しない。

地図の道路・建物を生成AIに再描画させたものではない。実際の建物・公園の形状から配置点を決め、生成済みのイラストを重ねる。道路は実データを最前面に描く。川の編み目模様・魔法陣は `src/map.ts` 内のSVG。

正確な生成プロンプトは `ASSET_PROMPTS.json`。第三者のゲーム画像や製品写真は使用していない。
