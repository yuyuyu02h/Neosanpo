# 異世界マップ：実装した方式と全国画像化の工程

## 今回動く方式

全国の実際の地図をOpenFreeMapから読み、表示中の建物・公園にAI生成イラストを重ねる。素材は城・塔・樹上の村・ケルトの砦と遺跡・地形の5点。川や湖には青い編み目模様と魔法陣。道路は実データをそのまま上から描く。

事前に地域ごとの画像を作らなくても、地物がある地域に同じ方式を適用できる。キー不要・静的配信だけで動作し、散歩のたびに生成費用は発生しない。地物がない地域に架空の建物をランダム配置することはしない。

これは「日本全国の地図を一枚ずつAIに描き直させた」実装ではない。建築物の種類は再利用される。全国の現地動作を検証済みでもない。

## 地域ごとの固有イラストへ進める方法

実現可能な設計として、地図を小さな区画に分けた画像（タイル）を用いる。MapLibreは座標付き画像とタイル画像の両方を扱える。[MapLibreのソース仕様](https://maplibre.org/maplibre-style-spec/sources/)。

1. OSMの地形・建物・道路データから、対象区画と周囲の余白を描く。
2. 道路・線路・水路・区画境界をマスクとして固定し、建物と緑地だけを画像生成で描き換える。AIへの文章指示だけで道路座標の正確さを保証しない。
3. 複数区画をまとめて生成し、周辺の重なりを確認して切り出す。隣接区画の色・建物・河川のつながりを検査する。
4. 生成画像の上に実データの道路を再描画。元の道路の位置と幅が変わっていないか画像と座標の両方で確認する。
5. 承認した画像を `z/x/y` で保存し、生成時点の地図バージョンと素材・プロンプトを記録。CDNから配信する。
6. 未生成の地域は今回の素材方式を表示する。まず利用のある小区域で品質・容量・生成費用を測り、範囲を広げる。

上記は設計であり、生成用サーバー・生成API・全国画像の保存先・大量生成処理は未実装。全国の画像を細かな倍率まで先に生成する場合、生成数・保存容量・更新費用が必要。実測なしに全国の費用や完了時刻を断定しない。費用が発生するサービスの契約・大量生成・公開は行っていない。

## データ取得と出典

[OpenFreeMapの導入資料](https://openfreemap.org/quick_start/) に基づく地図配信を使用。目的地と通行制限の取得は [Overpass API](https://wiki.openstreetmap.org/wiki/Overpass_API)。現在の公開エンドポイントと混雑を考慮し、周辺のみを取得する。地図の帰属表示を残す。全国一括取得のために公開APIへ大量の周辺検索を送る方式は採用しない。
